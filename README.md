# ThermoSolver
Thermodynamic equation solver

Works for Ti-Nspire CXii

Upload using this site https://nspireconnect.ti.com/nsc (only works with Chrome) 

**Lookup_optimized.tns** 
This is a pure table lookup file. Loads quicker than solver and less of an ethical dilmea. 

**solver_optimized.tns**
This has several solvers in it that allow you to input unknown variables and the program automatically solves for what it can. 

I used openclaw to scrape the tables and Codex to program this. If there's bugs then branch and fix yourself. I am not intending to maintain this.
